# Scientific result sources

- Phase A observations: `phase_a_rsm_blocking/results/`.
- Phase B observations and summaries: `results/phase_b/imdb/`.
- Development calibration: `results/phase_b_calibration/`.
- Publication figures and tables: `findings/phase_a/`, `findings/phase_b/` and `report/`.
- Quantities used in the paper: `report/metric_registry.json`.

Run `python report/build_evidence.py` to generate the paper's numerical tables and graphs directly from these records. Human-entered copies of empirical values are not maintained here.
